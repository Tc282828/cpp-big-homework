# 格温小姐大冒险

这是一个 C++ EasyX 课程大作业项目。

## 项目版本

v2.0 正式素材版

## 开发环境

- Visual Studio 2026
- C++17
- EasyX
- Windows

## 游戏操作

- Enter：开始游戏
- WASD / 方向键：移动角色
- R：胜利或失败后重新开始
- Esc：退出游戏

## 资源说明

游戏图片素材放在 `assets` 文件夹中。v2.0 版本已经使用正式图片素材，不再绘制临时地图、临时人物和临时技能。

如果运行时提示“图片资源加载失败，请检查 assets 文件夹”，请检查 `assets` 文件夹是否完整，以及图片文件名是否和代码中的路径一致。
